# Roadmap de AULA — Ideas para futuras versiones

Estas son ideas que el equipo identificó durante el desarrollo
pero que quedan para iteraciones futuras del producto.

## v2.0 — Visualización avanzada
- **Mapas mentales con Mermaid** — Gemma 4 genera diagramas
  Mermaid de conceptos complejos, renderizados visualmente
  en el chat. Ideal para estudiar relaciones entre temas.
- **Líneas de tiempo interactivas** — para historia, biología,
  ciencias sociales.
- **Diagramas científicos avanzados** — circuitos, química,
  matemática visual.

## v2.0 — Pedagogía
- **Quiz interactivo para el estudiante** — autoexamen al
  finalizar una sesión de estudio.
- **Plan de estudio semanal** — AULA arma un calendario de
  repaso basado en el historial del estudiante.
- **Modo examen** — simulacros temporizados.

## v2.0 — Plataforma
- **Sincronización entre dispositivos** — opcional, con cifrado
  end-to-end. La nube como respaldo, no como dependencia.
- **Compartir sesiones por código QR** — peer-to-peer entre
  estudiantes, sin servidor.
- **Modo offline real** — empaquetar AULA como app instalable
  con el modelo precargado en escuelas rurales.

## v3.0 — Comunidad
- **Profesores publican lecciones** — biblioteca compartida.
- **Modo grupo** — aula virtual con varios estudiantes.
